# 精神病理学を読むための小辞典

このページは、精神病理学に関する用語を整理するための小さな辞典である。

単なる定義ではなく、その用語がどのような問題意識の中で使われてきたのか、近接する概念とどこが違うのか、古典的な精神病理学と現代の診断分類のあいだでどのように位置づけられるのかを、少しずつ整理していきたい。

精神病理学の用語は、しばしば山道の標識に似ている。そこに言葉は立っている。しかし、その言葉がどの稜線へ続き、どの谷へ下っていくのかは、実際に歩いてみなければわからない。

この小辞典は、そのための山小屋である。
